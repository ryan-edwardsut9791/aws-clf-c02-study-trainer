## What is AWS Cloud Practitioner Trainer?

AWS Cloud Practitioner Trainer gives CLF-C02 candidates a straightforward study tool that does not depend on an installed application or an online service. Open the single HTML file in a web browser and study locally, making the trainer convenient to use across different devices and sessions.

Its main practice library contains 400 exam-style questions. Flashcards, spaced repetition, and mini-games provide additional ways to review concepts, while progress tracking and export/import features help organize study activity and preserve your data between runs.
